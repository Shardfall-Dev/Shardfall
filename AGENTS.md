# Shardfall collaboration

Use Shardfall-Dev/Shardfall as the source of truth for the ShardMMO project. Before changing the game, fetch the current branch, read README.md, and inspect the relevant source files and design documents. Share changes through a named branch or pull request and give collaborators the branch, commit, and relevant paths. Follow the current repository build and test instructions. Keep version identifiers on sound releases and asset packs.
