GET THE SOUND BUILD
Run these commands from an existing authenticated repository checkout:

  git fetch origin feature/sfx-v1.0.0
  git worktree add --detach ../shardfall-sfx FETCH_HEAD
  cd ../shardfall-sfx

Choose a free worktree path if that directory already exists. For a browser download, open PR #2, follow its head branch, and choose Code > Download ZIP. FILES TO USE
• assets/audio/manifest.json maps event IDs to versioned WAV paths and mix gains. Resolve each path relative to assets/audio/. Each row lists alternatives. Choose one take per event.
• assets/audio/sfx/ contains all 249 mono PCM WAVs. Try door.wood.open_01_v1.0.0.wav and skeleton.death_01_v1.0.0.wav first.
• src/audio.js owns unlocking, decoding, caching, mixing and voice limits. src/game.js owns weapon contact, doors, chest and corpse interactions, footsteps, creatures, crafting and quest events. src/magic.js owns active Magery casts and impacts.
• docs/Shardfall_Audio.md describes the integration. tools/embed_audio.py embeds browser audio when build.sh assembles the offline game. Shardfall_v0.17.html is the playable build in the verified snapshot.
• The SFX MIDI editor performances, custom Foley SoundFont and original preview are distributed in the separate original v1.0.0 authoring ZIP. Every effect required to run the game is present in GitHub as WAV.
