## Confirmed defects (P0/P1)
A01 [P0, reproduced] src/rules.js:390-399 SF.transfer accepts invalid quantities and same-container moves. With 10 gold, transfer -3 produces 13 in source and -3 in destination; qty 1.5 produces 8.5 and 1.5; explicit zero or NaN transfers all; moving full stack into its own container deletes it. Require finite positive safe integer, explicit omitted-qty semantics, reject same container (or defined safe no-op), enforce non-stackable quantity and validate item shape before mutation. Add regression tests for negative, zero, NaN, infinity, fraction, huge integer, identical container, versions and no mutation on error.
A02 [P0, reproduced] src/equipment.js:301-313,344-352: drop callback publishes a world item before final audit, and audit excludes external containers. With identical UID in pack and bank, drop returns OK, then bank + world hold same UID. With unrelated duplicate remaining in pack/bank, transaction can roll back the pack after callback side effect, duplicating an item. Separate validation/staging/commit, include all affected containers, rollback external side effects or use transactional world adapter. Audit also validate UID, item ID, qty, recursive ownership, not just duplicate values. No full-inventory scans per ordinary tick.
A03 [P1, static] src/game.js:222,2425-2439: save only serializes corpses with mine flag; player dropped piles and non-player corpse/chest contents not saved. Dropped gear disappears after reload; open/refill state regenerated by placeChest (1000) and interactExtra (1229), enabling repeated chest loot after reload if acquired loot saved. Decide explicitly what persists, implement stable chest IDs and remaining cooldown/contents, save player drops and define other corpse persistence. Validate in browser with save/reload.
A04 [P1, static] src/game.js:2425-2439; src/magic.js:46-56: preparing spell removes mana/reagents into escrow, but save omits prep; reload loses unresolved reservation rather than resuming or applying documented interrupt policy. Poison also omitted; reload can clear active poison. Other magical statuses intentionally not persisted per docs/magery/STATUS.md: document and test policy, including committed impacts and held casts. Do not refund twice or allow reload advantage.
A05 [P1, static] src/game.js:2439,2451-2456,2473-2478: loadSave accepts arbitrary JSON, character creation UI dereferences sv0.char.name; valid JSON with missing char can break startup. Parse error treated as no save; create can overwrite. Migration exceptions logged and boot continues into potentially invalid data. Validate schema/version and numeric values, isolate migration, retain last known good backup, show recovery/export/reset with confirmation. Add malformed, truncated, future version, quota, migration and multiple-tab scenarios.
A06 [P1, static] src/game.js:1926 displays obsolete pack stack limit SF.SLOTS and pack-only kg in loot panel despite weight-only spec. Replace with shared EQ total/cap weight formatter; verify equipment counts and thresholds across every UI. Legacy bag implementation 1882 also contains outdated counter; check whether reachable before removing.
A07 [P1, CI] .github/workflows/pages.yml: Check the build only runs rules and magery, deploys committed HTML without rebuilding/checking source-output drift. Add separate CI for all five suites, build freshness, syntax, manifests, smoke; no deploy on failures. Keep generated output policy consistent.
A08 [P1, configuration] Pages deployment fails as above; configure or intentionally disable until ready; check newer supported action versions separately.
