# Shardfall sandbox systems audit v1.0
Date: 2026-11-27. Baseline: main v0.28.1, 1a0a3fe8bab8dbf9ea6720eaf9e1c524bba1147d. Static source review, not runtime QA. No gameplay changes. Branches in development are not assumed merged.

## Current vs missing
- Living world: actors, event log, fixed step, clock/light, navigation, spatial index, seeded streams, wildlife habitats and factions, predation, packs, camp persistence, town schedules, needs and memory, travelling merchant and real resource workers are present. Shared human combat, witnesses, criminal/murder counts, NPC adventurers and NPC death/loot are already planned in WORLD_SIMULATION_PROGRESS phase 5. Finish existing plan rather than duplicate it.
- Crafting: mining, woodcutting, fishing, skinning, foraging, multiple craft professions, material variants, recipes, condition, repair, quality and maker names exist (rules.js, equipment.js, game.js). Rework economy, not crafting from scratch. Town workers deposit real resources into LIFE.stock (townlife.js around 197–211); vendor UI and buy/sell still use SF.PRICES and static SHOPS (game.js 1936–1938, 1984–1985). Proposed finite inventory, regional prices, real cargo, supply/consumption, gold ledger, recovery caps and atomic validation. Verify buy/sell authorization and quantity/price validation, stock/weight, and UI quote consistency.
- Taming exists: five explicitly tameable species (rat 25, boar/hound 55, snapper/spider 80), 4s attempt, 3m range, two control slots, basic follow/stay/attack/dismiss, Veterinary healing, Beast Handling command chance. See rules.js 627–628; game.js 1167–1193, 2367–2374, 857–869. Newer species including dire wolf, deer and bear need data review; do not assume all wildlife is tameable. Pet death removes actor without a corpse (game.js 451–452), dismiss removes actor, not return to ecology. Save 2425–2438 stores type/hp/name/slots/order/relative coordinates but not aid/owner, and 2489 recreates near player; original identity and distant stay location are not retained. Pet movement direct pursuit plus teleport beyond 24m, rather than robust shared navigation. No functional stable storage found; Dorn is placed in Skara Bryn and has dialogue (anniabreen.js 205–216,392). No mounted locomotion found.
- Exploration: Tracking, Search/detection, pickpocketing (smugglers only), lockwork, snares, loot chests, existing dungeon stairs and bosses exist. Expand into cartography, treasure maps, digging, secret passages, shipwrecks, varied traps, rare loot. Five frontier mouths are sealed per README v0.23; confirm current live state and build interiors incrementally: Hollowdeep, Wyrmhold, Liar's Keep, Sorrowstone, Gilt Maw.
- Magic: Mark/Recall/Gate, public moongates, runes, spellbook and 64 spells exist. Runebook not found. Ghosts, resurrection, bank, player corpses/full loot outside protected ground exist; extend common ownership/access/death rules.
- Factions: ecological relationships exist; guild quests exist. Town/player reputation, political membership, bounty economy, territorial control and player guilds not established.
- Maritime: fixed NPC ferry/boat/packet travel, fishing and ports exist. Player-piloted ships, ship ownership, cargo holds, sea exploration/combat not found.
- Housing: NPC buildings, doors, props, homes exist. Player land ownership, house placement, secure storage, furnishings and permissions not found.
- Immersion: day/night and lighting, lanterns, cooking/food, doors, sound, speech, NPC hunger/fatigue exist; full player hunger/thirst, camping, furniture interactions, weather/season simulation, books/noticeboards, dyes and collectible systems need verification or implementation; sound assets alone do not prove weather.
- Architecture: src/world.js, living.js, ecology.js, townlife.js; fixed step, actor IDs, event log, grid, partial persistence and reduced distant update rate. Extend versioned persistent world state, globally durable actor/item IDs, atomic transactions, simulation tiers, deterministic replay, shared NPC/player commands and eventual authoritative multiplayer boundary. Source review only: existing tests listed in README, not rerun here.

## Taming and Animal System v2 (proposed)
1. Use existing skill IDs/migrate display names to Animal Taming, Animal Lore, Veterinary in coordination with skill rework; no duplicate skills or lost points. Proposed 5 follower slots, including mounts and summons under one configurable ownership policy, with migration from two-slot limit.
2. Species data: tame difficulty, min skill, temperament, control slots, diet, mount/pack capabilities, habitat, combat profile. Low tier livestock/horses, mid tier wolves/bears, higher tier spiders/scorpions, elite drakes/dragons only when content and balance are ready. Values are design proposals, not verified UO formulas.
3. Timed attempts with checks for range, LOS, living wild state, owner, safe capacity, movement/interruptions and ecology membership. One authoritative atomic ownership transfer; do not duplicate animals or lose spawn accounting.
4. Explicit pet state machine wild/active/stabled/dead/released; immutable id, ownerId, origin, name, skills, stats, health, loyalty, order, absolute position and zone. Migrate legacy saves without duplicate pets. Persist target only when valid. Release back into ecology; prevent loot/respawn farming.
5. Commands follow/stay/stop/guard/attack/come/release; individual/all; server-ready command validation, range, control skill and criminal attribution to owner. Shared navigation, doors/stairs and explicit travel policy; no uncontrolled teleport across walls/zones.
6. Animal Lore inspect UI; diet, feeding and loyalty, bounded skill gain, optional bonding; Veterinary bandages, cure and bonded resurrection with explicit balance and interruption rules. Mount/dismount, pack animal inventory, death and stabling rules; stable UI at Dorn plus future towns. Keep riding artwork separate from first mechanical implementation.
7. Test skill migration, taming success/failure, invalid targets, repeated actions, caps, stable/retrieve, release, save/load while staying far away, pet death, commands/LOS/path, zone travel, mount slots, pack ownership, summons and law integration; desktop/mobile UI.
