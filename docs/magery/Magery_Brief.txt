SHARDFALL • MAGERY
Implementation brief for Claude

Integrate the 64 spells in spells.json into the existing web game. Start by finding the current input, hotbar, inventory, spell preparation, hit resolution, ghost, summon, save and world-collision entry points. Reuse them. Open Shardfall_Spellbook.html for the illustrated reference. Each card gives the Shardfall name, classic counterpart, original casting words, effect and costs. The eight rows of spell-signs.png run from Circle I at the top to VIII at the bottom. Each row has eight 128 × 128 icons. Use atlasRect or the individual PNG from art. Stable IDs are independent of names and texture positions.

Replace the old small launch spell list as the default book. Migrate only genuine equivalents from existing saves/hotbars (Mend → magery.04, Needle Spark → .05, Cleanse → .11, Ember Dart → .18, Step Between → .22, Greater Mend → .29, Mire Venom → .20, Cinder Seal → .43, Tidelance → .42, Brightmark → .48, Bellfire → .51, Wakecall → .59). Here and below .xx means magery.xx. Keep legacy-only abilities such as Sable Curtain addressable when old saves reference them. Ask the same mapping service to translate old quest rewards. Keep ownership, flags and quest state by stable IDs. Snapshot the old save before migration and make repeat migration harmless. Bind a discovered spell by dragging its sign on desktop or using “Assign to slot” on touch. In battle a tap starts prep, the target cursor releases and the journal shows the result. No automatic target selection.

Historical baseline and exceptions
The 1998 Origin playguide supplies period recipes. In particular Arcane Arrow uses black pearl + nightshade, Cinderball uses black pearl + sulfurous ash, and Delayed Explosion uses black pearl + mandrake root + sulfurous ash. Later UO changed recipes and spell damage. The reconstruction chooses 14 mana for circle V using era-shard spell pages and casting research. One UOSA Magery summary also prints 15. The eight baseline preparation times are 0.50/0.75/1.00/1.25/1.50/1.75/2.00/2.25 s. Add 6 s to the two fifth-circle summons. The same surcharge for eighth-circle summons is a Shardfall choice. The book section gives both the historical words and optional original Shardfall chants. Display the original Shardfall chant in the game; keep the historical words searchable in the reference.

The historic damage table in the spellbook is a set of observations. Numeric models in spells.json carry a basis field. “reconstruction” identifies a published era-shard formula. “documented bounds” preserves a reported historical range while choosing a distribution. “tuning” and “project” are Shardfall values. HP, swing rates, summon lifetimes, mana drain sizes, control caps, ward size and most durations are playable specifications. The old production binary and a complete late-1999 live tuning table were not verified. Do not label all these numbers exact OSI values. The classic book covers the T2A Magery school. Later expansion schools are separate systems.

Casting and spell resources
1. Map M to Spellcraft (UO Magery), E to Spell Focus (Evaluating Intelligence), R to the affected actor's Wardcraft (Resisting Spells). Skill units 0–100. Effective caster and target Intellect are attributes, independent of E. Use 1 magic tile = 1 metre for this profile. A, used by stat spells, is floor(M/10). Clamp(min,max,value) limits value inclusively. NdS sums N independent integers in [1,S]. Zero-HP utility effects do not generate hit events.
2. Discover spells by adding a full scroll to an owned spellbook. Learning consumes one scroll once. Casting a scroll directly requires its mana, waives reagent items and lowers the skill check by two circles. It preserves the original spell's timing, resistance difficulty and effect. Use scroll gate 0 for circles I and II. For higher circles use that lower circle's minimum. Grant starter characters who select magic at least 10.0 Spellcraft and the two starter pages Lesser Mend and Arcane Arrow. The practice ring supplies a disposable loadout.
3. Start with free hands. At start, reserve mana and all reagents (one each), or one scroll. Announce the chant and show the sign over the caster. During prep, moving over 0.3 m or taking positive hostile damage interrupts. Lesser Mend and Arcane Arrow allow walking at 70% speed as in the project brief. Death cancels the action. Failed skill check at prep completion consumes reserved resources and full mana. An ordinary interrupt/cancel during prep costs half mana rounded up and releases item reservations. These resource rules and interruption behavior follow the Shardfall prototype design.
4. Use the book gate in spells.json. For circles I–VI interpolate book success linearly from .02 at the gate to .99 at 40.1, 50.1, 60.1, 70.1, 80.1, 90.1 respectively. For VII and VIII use .02 + .025 × (M−gate), capped at .99. Below gate the book cast cannot start. For scrolls, chance = clamp(0,1,.025 × (M−scrollGate)). Skill success roll is separate from recipient resistance. Seed all rolls from the authoritative simulation. A successful prep charges once and holds the spell for 3 s. A held spell can be released while moving. Recovery is 350 ms after release, fizzle, interruption or expiry. Rejected targets leave the existing hold timer running. Use 50 ms ticks; round durations up. Same request ID always yields its recorded outcome.
5. Ground anchors and characters require line of sight at release. Ground-or-living anchor means use the selected actor's location at release, then fix that point. Check individual area recipients at impact, using world collision, living status, practice boundary and attribution. A committed single-target hit follows the recipient inside the same world instance even after losing sight. Death or instance change invalidates it. Persist scheduled impacts across brief disconnects as appropriate. Reject repeat resolution by event ID. Member spells each carry their own impact delay separate from preparation; only the affected victim sees any private immunity result.
6. Apply the direct damage method below instead of also running the old flat spell-damage multiplier. Full-loot attribution, practice-ring floor and the optional rolling PvP burst ceiling belong to the outer combat service. For historical measurements, disable the ceiling, outlaw-recovery multiplier and ring floor in the test fixture. In the live game, report their adjustment in the combat log.

Damage and resistance
Use one resistance roll per affected actor per impact. Let C=1..8. Resist probability = clamp(0,1, max(R/5, R−((M−20)/5 + 5×C))/100). For half_then_focus, if resisted multiply base by .5. Then multiply by 1+(E−R)/(E<R ? 200 : 500). Round down once at the end; allow zero. Equality gives 1. Record the raw roll, resist result and applied HP. The same premitigation formula works for creatures if their templates supply E, M and R. No automatic PvE double damage. Fire, lightning, and arcane cues identify the spell; this pre-AoS profile uses a common resistance skill.
• half_only applies half on a successful resist, then floors. Mindburst uses its own Intellect rule and can backfire. Use the actual recipient's R, the original cast's M and no E correction. Earthshaker applies its percentage separately without a resist or Focus multiplier.
• negates cancels the effect on successful resist. poison_tier lowers the incoming tier by one on resist; tier zero means a full resist. The spell uses the project's poison family, four ticks spaced two seconds apart. A higher tier replaces a weaker one while preserving the next pending tick; equal or weaker applications leave the current instance and expiry intact. Historic UOSA spell poison ranged from regular to greater and poison used percentage-based damage. Shardfall keeps its existing three-tier HP damage system. This is a deliberate difference.
• duration uses only the duration scaling below. banish_check uses the conjuration-specific roll. none bypasses resistance. The term “no direct HP damage” does not rule out mana removal, physical reflection or later creature damage, which have separate entries.
• Reflection is checked only where reflectable=true, on release before scheduling damage. Consume it once and exchange effect source and recipient. Keep cast strength and original instigator for the aggression log; drain/transfer credits the actor now acting as effect source. A reflected event carries a one-bounce flag. All area attacks, triggered traps, recoil, self-centered effects and Mindburst bypass the mirror.
• Direct area hits share one rolled pool. Gather distinct eligible victims excluding the caster in line of effect at impact. Allocate integer quotient to each and distribute the remainder by increasing distance from center, breaking ties by entity ID. Then roll resistance independently for each share. With no eligible victims, discard the pool. No double counting a hidden creature or a large creature occupying multiple tiles. Positive offensive area damage reveals magical invisibility.
• Keep project practice ring, law and combat travel policies. Neutral players and allies can be struck by fields and area offense under ordinary world rules. A helpful area pulse can reach any legal living actor, including its caster. Check aiding an offender individually. Traps, pets, field ticks and poison ticks carry their original source across logout. Each target gets one attributable aggression record per cast rather than one criminal timer per animation frame.

Statuses, terrain and ownership
Stat boons and physical armor last 20 + floor(M) seconds. A hostile stat effect lasts (20 + floor(M)) × (1−.005R) s. Maintain at most one strongest active positive and one strongest active negative contribution per stat. Equal strength may refresh an effect; an opposite contribution combines algebraically. Example +8 STR and −10 STR gives −2. A stronger boon supersedes the weaker one. Transient effects may push a normal attribute outside its training cap; clamp effective values to [1,125]. Recalculate derived caps from effective stats, clamp current pools downward and never fill pools on a cap increase. Clamp living HP to at least 1 during stat recalculation. Remove temporary buffs, disguise, invisibility and transformation on death.
Rebounding Armor lasts 120 s or until exhausted. Mirror Ward lasts until it reflects a spell or the ward bearer dies. These wards replace one another on successful application; Protection is a separate armor bonus and can coexist. Physical retaliation cannot trigger another ward retaliation. Double-casting one ward refreshes it. An attempted hostile single-target stat hex can spend a mirror charge even if a stronger hex is already active.
Bind duration = (2 s on players, 4 + .08M s on ordinary NPCs) × (1−.003R). Disallow bosses marked control-immune. Break bind on any positive HP damage, including poison and trapped pouches. Shared control immunity begins on removal and lasts 6 s. A player can still act while rooted. Wall of Paralysis requires a fresh entry after immunity. Entering a fire field pulses immediately; further pulses within the same cast require a full second, even after stepping between segments. One poison-field application attempt per entry, per creature, plus one retry after 2 s of uninterrupted exposure if no poison is active.
Snap field lines to the nearest cardinal axis perpendicular to caster→target. For even lengths n, indices along the positive canonical axis are −n/2+1 through +n/2 (a four-tile wall centered at zero occupies −1,0,1,2). Exclude occupied or illegal tiles for solid barriers. Nonblocking fields can overlap creatures and apply entry effects. Clip at walls and reject an empty footprint; never span excluded private/guarded geometry through a blocked segment. Each segment has a cast ID, source, index and absolute expiry. Prevent blocking a fixed protected arrival, shrine or mandatory town exit.
Recall, Mark and Gate use durable map, instance policy, x/y and elevation on a rune. Travel rejects overweight, rooted, combat-locked, dead, unauthorized house and blocked endpoints. Gate entry is voluntary with explicit player confirmation; validate at step time. Debounce 1 s plus leaving the destination mouth before hopping again. Followers travel with their owner only if they independently qualify. A dispelled entrance stops accepting entries. Keep its anchor while the other mouth lives. Blink is a short tactical action during combat, subject to its own valid landing and line-of-sight check.
Container magic only operates on an object the actor is permitted to manipulate in the current context. Trapping an eligible door or container journals its owner; open triggers once. Remote activation targets the opener only when within one tile of the latch. An empty or distant activation consumes the charge. The trap uses the original mage's M/E and its opener's R. Lock, trap and ownership are independent states. Bootstrapping the inventory: map equivalent existing materials by explicit item IDs where the game already defines them; otherwise introduce the eight reagent items from spells.json. Never merge inventories because two names sound similar.

Summons and pets
Use the stat block in the spell record. All listed HP amounts are premitigation. A summon itself deals zero damage at the moment of casting. Duration defaults to floor(4M) s for controlled summons and 90 s for uncontrolled summons. Two available pet slots per owner, one damage pet actively engaging in PvP. Entry in an unavailable slot rejects the target. A player command requires owner line of sight to the victim within the existing 12 m command limit. Uncontrolled summons select a legal living target within 6 tiles. Spirit Blades prefer highest Tactics, then nearest; Vortex prefers highest Intellect, then nearest. Resolve remaining ties by stable entity ID. Include neutrals, allies and the owner in wild selection, subject to practice boundaries. Vortex has 25% chance to apply tier-two poison on each landed melee hit. Normal summon melee follows the NPC hit and armor rules; ranged attacks use the same NPC hit resolution with spell resistance set to half_only, using the summoner's M and summon circle. Use a single attack timer so ranged and melee attacks cannot fire simultaneously. In melee reach (≤1 tile) use melee; otherwise use the listed ranged interval and range. If rangedMax=0, close to melee. Ordinary controlled animals use their conjured stat block; no loot, skinning or corpse resources from summons. Banish chance = clamp(.05,.95,.50 + (M−banishDifficulty)/100 + (.10 for Mass Banishment)). Despawn once on banishment, death or expiry. Controlled summon PvP per-hit caps, if already in the game, must be exposed in the combat log and configured independently of the base stat block.

Delivery checks
• All 64 records have a unique ID, eight entries per circle, an icon, a classic name and a nonempty recipe. Artwork appears in the spellbook and hotbar. Test a touch long-press, keyboard focus and rebinding after save/load.
• At M=100 roll Cinderball at both extremes: 13 and 18 base. Greater Mend heals 41–50 before target HP cap. Equal E and R leave raw unresisted hit unchanged. M=E=R=100, circle VI gives 54% resist. A raw 30 hit deals 30 or 15 before outer rules. Historical averages belong in diagnostics only.
• Start a held Delayed Explosion, release at t=0, begin Aether Bolt at .35 s, release it at 2.10 s. Explosion lands at 2.00 s, bolt at 3.10 s. Check that moving either source or target after release cannot reapply damage. Both successes spend 40 MP altogether.
• M=100, 100 INT against 76 INT: Mindburst deals 6 unresisted or 3 resisted. Reverse those scores: the caster takes the damage. Equal scores deal zero. The mirror charge survives all three cases. Rebounding Armor absorbing a melee hit of 10 from a pool of 25 leaves 15 and returns 2 damage.
• Split a 41-point meteor pool among three equidistant lawful targets: stable IDs receive 14, 14, 13 before resistance. A single missing recipient must not leave a share held over for the next cast. A 91-HP target hit by Earthshaker becomes 46 HP.
• A failed ancient lock attempt leaves the trap armed. Remote activation from 9 m spends a rune trap without hurting the remote user. A point-blank pouch opening that deals damage breaks the user's bind.
• Reconnect between Mark and Recall. Test combat-lock rejection, repeat gate-entry packets, simultaneous dispel and entry, opposing locked doors and blocked elevations. Restoration offers to a ghost that already revived do nothing. Corpse inventory is never moved by revival.
• Learn by scroll, spend a scroll to cast and interrupt before completion. Inventory debit and mana must agree with the ledger after a retry. Prepping validates the book or scroll; do not let a client grant itself unknown spells.
• Place five wall segments at a bridge, remove the middle one and verify collision and local line-of-sight changes. Walk through adjacent fire tiles within one second and see one pulse. Leave and re-enter a bind field while immune. End a summon by dispel and expiry in the same tick and verify one slot release.

Use magery-math.mjs for the book's exact roll distributions, resistance chance and premitigation benchmarks. The standalone HTML contains the same routines for offline use. Run “node verify.mjs” from the unpacked directory to exercise the deterministic reference cases. The module implements the portable calculator; world targeting, ownership, persistence and combat integration are specified above.

Where this fits in the current web prototype
• Shardfall.html exposes castSlot(id), prepTick(), interruptPrep(msg), releaseHeld(t), spellDmg(base), applySpell(sp,t) and slotLabel(s). The spell collection is SF.SPELL. Use the source module behind that bundled HTML if the editable project has one. Adapt castMs/impactDelayMs to the simulation's seconds exactly once. Leave sprite loading, input layout and the existing cast-release animation in place.
• castSlot currently requires an auto-selected creature for an enemy spell before prep. Move target selection to release so Explosion can actually be precast. releaseHeld currently accepts only monsters as enemies and substitutes self for some ally selections. Add explicit player, pet, ghost, rune, door, container, field tile and ground-target adapters. A mistaken tap should preserve a held spell and show which target is required.
• prepTick currently contains an if(false) expiry branch and self-casts dispatch directly to applySpell. Wire the three-second deadline and the same recovery debit on self-casts. Expose actual R of the recipient to the resolver; the current spellDmg passes zero. Curing currently looks at P.poison; route treatment to the selected patient.
• The current recall branch chooses P.bound from SHRINES. Rune Recall needs its own marked-item endpoint. The current summon branch always constructs a Reedling. Use the per-spell template and control mode. The current revival path logs a message for another player; connect consent to a real ghost or a local two-actor test fixture. Treat server replication as a separate step from the working local spell simulation.
